## Light Ray

Light Ray is a variant of [LIGHT Shaders](https://modrinth.com/shader/light-shaders) (Chocapic13's Shaders fork), aimed at providing advanced features such as ray tracing and PBR while maintaining performance.

### Features

#### Ray tracing.

Screen-space ray traced global illumination, bouncing colored light around the scene for a more grounded, physically inspired look.

#### PBR shading.

LabPBR materials with metalness, roughness and emissive support for a richer surface response.

#### Performance first.

Built on top of LIGHT Shaders' optimized base, so the advanced features do not come at the cost of your FPS.

---

### Requirements

- Iris Shaders, Oculus Shaders or OptiFine.
- OpenGL 1.2 support.
- An ordinary GPU. (even extremely below average)
